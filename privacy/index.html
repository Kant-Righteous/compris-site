Compris Privacy Policy

Effective date: September 13, 2026

Compris is an AI-assisted French reading, translation and dictionary app for Android ("the App"), provided by the developer identified in the Contact section below ("we", "us").

Short version: we do not collect, receive, or store any of your data on any server. The App has no developer-operated backend, no account system, no analytics, and no advertising. Everything you do in the App stays on your device, except the AI requests described in Section 3, which are sent directly from your device to the AI provider you choose and configure.

1. Data stored on your device

The following data is stored locally on your device only, and is never transmitted to us:

  • AI provider settings and API keys. API keys you enter for your AI providers are stored in the Android platform secure storage (Android Keystore). They are never sent to us, never written to logs or history records.
  • Understanding history. Your reading history and AI-generated explanations are stored in a local database on the device.
  • Preferences and settings. Interface language, explanation language, and other settings.

2. Data we do not collect

  • No account or registration — the App works entirely without one.
  • No analytics, telemetry, or crash-reporting SDKs.
  • No advertising or ad identifiers.
  • No tracking, profiling, or device fingerprints.
  • We never receive copies of your reading texts, history, or API keys.

3. Data sent to third-party AI providers

When you use the understanding features, the App sends requests over HTTPS directly from your device to the AI service endpoint that you have configured yourself (for example OpenAI, Anthropic, Google Gemini, DeepSeek, or your own self-hosted server). These requests typically contain:

  • the French text you selected, plus limited surrounding context needed to interpret it;
  • your question or chosen understanding mode;
  • technical instructions needed to obtain a structured answer.

Because the requests go directly to the provider you chose:

  • we cannot see, intercept, or store them — we operate no server involved in this communication;
  • how the provider handles that data is governed by that provider's own privacy policy and terms, which you should review;
  • if you configure a provider endpoint of your own, the data goes only where you point it.

4. Backup and export files

The App lets you manually export a backup file (for example to migrate to a new device) and import it back. Backup files are written only to locations you choose, and are entirely under your control — we never receive them. Optionally, and only after an explicit in-app risk warning, you may include your API keys in a backup file. Backup files that contain API keys are sensitive: keep them safe and delete them when no longer needed.

5. Permissions the App uses

  • Internet — to send your AI requests to the provider you configured.
  • File selection — used only when you explicitly import or export a backup file, via the Android file picker.

6. Data retention and deletion

  • All local data (history, settings, stored API keys) is deleted when you uninstall the App.
  • You can delete history entries or stored API keys at any time from within the App.
  • Backup files you exported remain where you saved them and are under your control.

7. Children's privacy

The App is not directed at children under 13, and we do not knowingly collect any personal information from anyone, including children.

8. Security

The App uses HTTPS for all network communication and the Android platform secure storage (Android Keystore) for API keys. No method of transmission or storage is absolutely secure, but because your data never passes through servers operated by us, the most common centralized-breach risks do not apply.

9. Changes to this policy

If we change this policy, we will post the updated version on this page with a new effective date. Material changes will also be reflected in the App's release notes.

10. Contact

If you have questions about this policy, contact us at: greenbean.ai.app@gmail.com

Compris 隐私政策

生效日期：2026 年 9 月 13 日

Compris 是一款 Android 平台上的 AI 辅助法语阅读、翻译与词典应用（下称"本应用"）， 由联系方式一节所列的开发者（下称"我们"）提供。

简要说明：我们不在任何服务器上收集、接收或存储你的任何数据。 本应用没有开发者运营的后端，没有账号系统，没有统计分析，也没有广告。你在应用内的一切 数据都只保留在你的设备上；唯一的例外是第 3 节所述的 AI 请求——它从你的设备直接发送给 你自己配置的 AI 服务商。

一、存储在你设备上的数据

以下数据仅存储在你的设备本地，永远不会传输给我们：

  • AI 服务商设置与 API 密钥。你填入的 API 密钥存储在 Android 平台安全存储（Android Keystore）中，不会发送给我们，也不会写入日志或历史记录。
  • 理解历史。你的阅读历史与 AI 生成的讲解保存在设备上的本地数据库中。
  • 偏好与设置。界面语言、讲解语言等设置项。

二、我们不收集的数据

  • 无账号、无注册——本应用完全不需要账号即可使用。
  • 不集成任何统计、遥测或崩溃上报 SDK。
  • 没有广告及广告标识符。
  • 不做追踪、画像或设备指纹。
  • 我们永远不会收到你的阅读文本、历史记录或 API 密钥的副本。

三、发送给第三方 AI 服务商的数据

当你使用理解功能时，本应用会通过 HTTPS 将请求从你的设备直接发送到 你自己配置的 AI 服务端点（例如 OpenAI、Anthropic、Google Gemini、DeepSeek，或你自建的服务）。 这些请求通常包含：

  • 你选中的法语文本，以及理解它所需的少量上下文；
  • 你的提问或所选的理解方式；
  • 获得结构化回答所需的技术性指令。

由于请求直达你所选择的服务商：

  • 我们无法看到、拦截或存储这些请求——整个通信过程中不存在由我们运营的服务器；
  • 服务商如何处理这些数据，由该服务商自己的隐私政策与条款决定，建议你查阅；
  • 如果你配置的是自建服务端点，数据只会发送到你自己指定的地方。

四、备份与导出文件

本应用支持手动导出备份文件（例如迁移到新设备）并重新导入。备份文件只会写入你选择的 位置，完全由你掌控——我们永远不会收到它。在应用内明确提示风险后，你可以选择将 API 密钥 一并包含在备份文件中。包含 API 密钥的备份文件属于敏感文件：请妥善保管，不再需要时请删除。

五、本应用使用的权限

  • 网络——用于向你所配置的 AI 服务商发送请求。
  • 文件选择——仅在你主动导入或导出备份文件时，通过 Android 文件选择器使用。

六、数据保留与删除

  • 卸载本应用即删除全部本地数据（历史、设置、已存 API 密钥）。
  • 你可以随时在应用内删除历史记录或已存的 API 密钥。
  • 你导出的备份文件保存在你存放的位置，由你掌控。

七、儿童隐私

本应用不面向 13 岁以下儿童，我们也不会有意收集任何人（包括儿童）的个人信息。

八、安全

本应用的所有网络通信均使用 HTTPS，API 密钥存储于 Android 平台安全存储 （Android Keystore）。任何传输与存储方式都无法做到绝对安全，但由于你的数据从不经过 我们运营的服务器，最常见的集中式数据泄露风险在这里并不存在。

九、政策变更

如果我们变更本政策，会在本页面发布更新版本并注明新的生效日期。重大变更也会在应用的 版本说明中体现。

十、联系方式

如果你对本政策有疑问，请通过 greenbean.ai.app@gmail.com 联系我们。
