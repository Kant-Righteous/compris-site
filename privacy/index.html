Compris Privacy Policy

Updated: September 19, 2026

Who provides Compris

Compris is provided by Green Bean Man. Contact: greenbean.ai.app@gmail.com. This policy covers the Android app and explains the separate role of the public website at https://kant-righteous.github.io/compris-site/privacy/.

Compris helps with vocabulary, reading, expression and language explanations using AI. Its current interface languages include Simplified Chinese, English, French, Spanish and Italian; its current learning (target) languages include French, Spanish, Italian, English and Simplified Chinese. Available results depend on the model and language configuration; they may be inaccurate.

Local data and developer services

The current app has no Compris account, developer-operated AI relay, advertising SDK, analytics SDK or automatic crash-report upload. This does not mean that no data leaves the device: AI requests go to your configured provider, and files or support messages you choose to send may reach other services. Apart from the AI endpoints you configure, the app makes no other network connections: no update checks, no remote content downloads, no telemetry endpoints.

The app stores understanding history (including original input and generated results), preferences, language choices, provider settings, model discovery/capability information and diagnostic records in its local application storage. History and settings use an ordinary local database, not a separately encrypted database. Android's app isolation and device security also affect protection.

API keys entered in the dedicated key field use platform secure storage through flutter_secure_storage, with encryption keys protected by Android Keystore. The API key itself is an authentication credential sent to the configured endpoint. It is not added to understanding history or diagnostic payloads by the app. Text or custom request parameters you enter elsewhere can themselves contain secrets; those fields do not receive the dedicated API-key protection.

When data leaves the device

When you request an understanding, a follow-up, additional expressions, a retry or a real AI test, the app sends data directly to the AI endpoint you configure. Requests may include the original input, questions, selected passages, the current understanding result, previously generated candidates (including earlier batches), language/learning preferences and system instructions. A follow-up can include the full current result, not just the highlighted words. Parsing repairs can send the original input, a previous response and validation feedback. The app does not automatically upload the entire history library.

Connection checks and model discovery send your API key and technical requests; capability tests send fixed test content. Provider requests include a model identifier and may include advanced request parameters you configured. The receiving service also sees connection metadata such as your IP address and request time, and may associate requests with its account or API project. Some providers derive an approximate region or country from an IP address; for example, OpenRouter describes passing the originating country to upstream models.

AI endpoints must use HTTPS; apart from that requirement, these requests follow standard HTTP redirect behavior, which means an endpoint that responds with a redirect could forward the request, including its Authorization header, to another address. Only configure endpoints you trust. HTTPS protects the connection to the selected endpoint. It does not establish that a custom endpoint is trustworthy or control a provider's onward processing.

Independent AI providers and custom endpoints

The app offers templates for OpenAI, DeepSeek, Gemini, OpenRouter, AgnesAI, Kimi, MiMo, GLM/Z.ai, Qwen and compatible custom endpoints. A template is a configuration convenience, not an endorsement or a guarantee of availability. This version uses an OpenAI-compatible protocol; a native Anthropic adapter is not supported.

Providers, gateways and their upstream model services apply their own terms and privacy policies. Their retention periods, training use, abuse monitoring, human review, subprocessors, processing countries and deletion options vary by service, region, subscription and account settings. A gateway may forward content to another provider. Green Bean Man does not set those independent practices or promise zero retention, no training, EU-only processing or universal deletion on their behalf. Review the terms of the actual endpoint and account you use. Changing a display name or using a custom URL does not change the service's terms.

Diagnostics

Diagnostics are local and are not automatically uploaded to Green Bean Man. Basic records include event/outcome, provider/model identifiers, endpoint host, error codes and timing. Optional detailed performance logging adds request/response sizes, token counts, output strategy, validation codes and performance measurements. The diagnostic export can also include app version and platform. Full response bodies are never stored. In the default basic mode, storage and export also exclude response previews, provider error summaries and response object key names. If you enable the optional detailed logging, sanitized and truncated response previews, provider error summaries and response object key names are additionally recorded (API keys and key-like strings are redacted) and appear in exports. Provider/model names and hostnames may still identify your service configuration; inspect an export before sharing it.

The app keeps at most 500 diagnostic records; records older than seven days are deleted when new records are written, and stale records are hidden from the diagnostics screen. This is not a background deletion timer. Upgrading removes legacy response preview/error-summary fields from active diagnostic database records. Previously exported logs and forensic remnants are not erased by that migration. You can clear diagnostics within the app.

Backup, import and export

Backup JSON files are not encrypted by Compris. You choose which history, settings and provider configurations to export and where to save the file. Dedicated API keys are excluded by default; including selected keys requires an explicit choice and risk acknowledgement. Advanced request parameters are ordinary provider configuration and can contain other secrets you entered. Review the full export contents, even when the API-key option is off.

On Android, imports read the document you select into memory through the system document picker without making a new Compris disk-cache copy. Older app versions or your document provider may have cached copies. Android's app cache controls can remove old app cache files. Importing a backup does not send it to an AI provider, but subsequent AI use of imported history can send the current context as described above.

Exports remain at the destination you select. A cloud document provider may upload or synchronize them under its own policy. Compris does not operate an automatic backup/sync service and requests exclusion of its private app data from Android cloud backup and device transfer. Device vendors and external file providers control their own behavior.

Support communication

If you email greenbean.ai.app@gmail.com, Green Bean Man receives your email address, message, and any files or other details you include. This information is used to respond, investigate problems and handle privacy requests; the email service also processes it under its own terms. Do not send API keys or unneeded private text. Support correspondence may be retained for handling the issue, follow-up and applicable obligations. You may request deletion at that address; any applicable retention exceptions will be explained when handling your request. There is no automatic support-email deletion schedule implemented by the app.

Retention and deletion

Local history and settings remain until you delete them, replace them through an import where applicable, or clear the app's data. You can delete individual history entries or all history, remove provider/API-key configurations, and clear diagnostics. Clearing local history does not delete local diagnostic metadata, external backups, email correspondence or copies held by AI providers. Removing a stored key does not revoke it at the provider; revoke exposed keys in that provider's account.

Android normally removes private app data when you clear app storage or uninstall. Exported files, document-provider caches, transfers made outside the app and third-party records may remain. Delete exported files separately and contact the relevant AI or file provider for its retention and deletion controls. There is no Compris online account to delete, and Green Bean Man cannot delete data held in your independent provider account through the app.

Age and responsible use

Compris is not designed for children under 13. AI use must also meet the actual provider's age, country and account requirements and any applicable guardian-consent rules. Some services have stricter limits: Gemini API and OpenRouter have adult-use restrictions. A parent's consent alone does not override a provider's prohibition. The app currently does not verify age or collect a date of birth. Avoid entering personal information about children or others without appropriate authority.

Permissions, website and changes

The Android app uses Internet access for provider requests and the system document picker for files you select. It does not request contacts, microphone, camera or location permissions. Your keyboard, operating system and chosen document services have their own data practices.

The app bundles a copy of this policy for offline reading under Data & privacy; the public address above always carries the latest version. Opening the public website in a browser makes a separate connection to GitHub Pages; GitHub can process IP addresses and technical request information under its privacy statement: https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement. The website source does not include analytics or advertising scripts.

Updated policies will appear at the public address above with an updated date. For questions or requests about information received by Green Bean Man, contact greenbean.ai.app@gmail.com.

Compris 隐私政策

更新日期：2026 年 9 月 19 日

提供者与产品

Compris 由 Green Bean Man 提供。联系邮箱：greenbean.ai.app@gmail.com。本政策适用于 Android 应用，并说明公开网站 https://kant-righteous.github.io/compris-site/privacy/ 的独立数据处理。

Compris 使用 AI 辅助词汇理解、阅读、表达与语言讲解。当前界面语言包括简体中文、英语、法语、西班牙语和意大利语；当前学习（目标）语言包括法语、西班牙语、意大利语、英语和简体中文。具体结果取决于模型与语言配置，可能存在错误。

本地数据与开发者服务

当前应用没有 Compris 账号系统、开发者运营的 AI 中转服务、广告 SDK、分析 SDK 或自动崩溃报告上传。这不代表数据不会离开设备：AI 请求会发送给你配置的 provider，你主动发送的文件或支持邮件也可能到达其他服务。除你配置的 AI endpoint 外，应用不会发起任何其他网络连接：没有更新检查，没有远程内容下载，没有遥测端点。

应用在本地应用存储中保存理解历史（含原始输入和生成结果）、偏好、语言选择、provider 设置、模型发现与能力信息以及诊断记录。历史与设置使用普通本地数据库，并非单独加密的数据库；Android 应用隔离和设备自身的安全状态也影响保护效果。

专用 API key 输入框中的密钥通过 flutter_secure_storage 使用平台安全存储，其加密密钥由 Android Keystore 保护。API key 本身作为身份验证凭据发送给配置的 endpoint。应用不会把该字段自动加入理解历史或诊断正文。你在其他文本或自定义请求参数中输入的内容也可能含有密钥，这些字段不具备专用 API key 字段的存储保护。

数据何时离开设备

当你发起理解、追问、补充表达、重试或真实 AI 测试时，应用会从设备直接向你配置的 AI endpoint 发送请求。请求可能包括原始输入、问题、选中文字、当前理解结果、此前生成的候选（含更早批次）、语言与学习偏好以及系统指令。追问可能包含完整的当前结果，不仅是高亮词语。格式修复可能再次发送原始输入、先前响应和校验反馈。应用不会自动上传整个历史库。

连接测试和模型发现会发送 API key 与技术请求；能力测试发送固定测试内容。provider 请求含模型标识，也可能包含你配置的高级请求参数。接收服务还会看到 IP 地址、请求时间等连接信息，并可能将请求关联到其账号或 API 项目。一些 provider 会根据 IP 地址推断大致地区或国家；例如，OpenRouter 说明其会向上游模型传递请求来源国家。

AI endpoint 必须使用 HTTPS；除该要求外，这些请求遵循标准 HTTP 重定向行为，即返回重定向的 endpoint 可能把请求（包括 Authorization 头）转发到其他地址。请只配置你信任的 endpoint。HTTPS 保护设备与选定 endpoint 之间的连接，不能证明自定义 endpoint 值得信任，也不能控制 provider 的后续处理。

独立 AI provider 与自定义 endpoint

应用提供 OpenAI、DeepSeek、Gemini、OpenRouter、AgnesAI、Kimi、MiMo、GLM/Z.ai、Qwen 及兼容自定义 endpoint 的配置模板。模板只是配置便利，不代表背书或可用性保证。当前版本使用 OpenAI-compatible 协议，不支持原生 Anthropic 适配器。

provider、网关及其上游模型服务有各自的条款和隐私政策。保留期限、训练用途、滥用监测、人工审核、分包商、处理国家与删除方式会因服务、地区、套餐和账号设置而异。网关可能将内容转交其他 provider。Green Bean Man 不决定这些独立行为，也不替它们承诺零保留、不训练、仅在欧盟处理或全面删除。请核查实际 endpoint 和账号适用的条款。修改显示名称或使用自定义 URL 不会改变服务条款。

诊断

诊断保存在本地，不会自动上传给 Green Bean Man。基本记录包含事件与结果、provider/模型标识、endpoint 主机名、错误代码和耗时。可选的详细性能日志增加请求/响应大小、token 数量、输出策略、校验代码和性能测量；诊断导出也可能包含应用版本和平台。响应正文永远不会被存储。默认的基本模式下，存储与导出还排除响应预览、provider 错误摘要及响应对象键名。如果启用可选的详细日志，经过脱敏和截断的响应预览、provider 错误摘要及响应对象键名会被额外记录（API key 及疑似密钥的字符串会被遮蔽）并出现在导出中。provider/模型名称和主机名仍可能识别你的服务配置，分享前请检查导出文件。

应用最多保留 500 条诊断记录；超过七天的记录在写入新记录时删除，过期记录在诊断界面中隐藏；这不是后台定时删除。升级会移除当前诊断数据库记录中的旧响应预览和错误摘要字段，不能抹去此前导出的日志或取证残留。你可以在应用内清空诊断。

备份、导入与导出

Compris 不加密备份 JSON。你选择导出的历史、设置和 provider 配置，以及保存位置。专用 API key 默认不导出；导出选定密钥需要主动勾选并确认风险。高级请求参数属于普通 provider 配置，可能包含你输入的其他密钥。即使未勾选 API key，也应检查完整导出内容。

Android 导入通过系统文档选择器将你选定的文档读入内存，不会新建 Compris 磁盘缓存副本。旧版应用或文档 provider 可能留下缓存；Android 的应用缓存管理可以清除旧应用缓存文件。导入本身不将备份发给 AI provider，但之后使用导入历史进行 AI 交互时，可能按上文说明发送当前上下文。

导出文件保留在你选定的位置。云文档 provider 可能按其政策上传或同步。Compris 不运营自动备份/同步服务，并请求 Android 云备份和设备迁移排除私有应用数据。设备厂商及外部文件服务控制其自身行为。

支持通信

当你发送邮件至 greenbean.ai.app@gmail.com 时，Green Bean Man 会收到邮箱地址、邮件正文以及你附带的文件或其他信息。这些信息用于回复、排查问题和处理隐私请求，邮件服务也按其条款处理信息。请勿发送 API key 或不必要的私密文本。支持通信可能为问题处理、后续跟进和适用义务而保留。你可通过该邮箱申请删除；处理请求时会说明适用的保留例外。应用没有实施支持邮件自动删除时间表。

保留与删除

本地历史和设置保留至你删除、在适用的导入操作中替换或清除应用数据。你可以删除单条或全部历史、移除 provider/API key 配置，以及清空诊断。清除本地历史不会删除诊断元数据、外部备份、邮件通信或 AI provider 持有的副本。删除本地 API key 不会在 provider 处撤销密钥；泄露密钥应在该 provider 账号中撤销。

Android 通常会在清除应用存储或卸载时删除私有应用数据。导出文件、文档 provider 缓存、应用以外产生的迁移副本及第三方记录仍可能保留。请单独删除导出文件，并向相应 AI 或文件 provider 查询保留与删除控制。Compris 没有需要删除的在线账号，Green Bean Man 无法通过应用删除你独立 provider 账号中的数据。

年龄与负责任使用

Compris 不面向 13 岁以下儿童。AI 使用还必须满足实际 provider 的年龄、国家和账号要求，以及适用的监护人同意规则。一些服务限制更严格，例如 Gemini API 和 OpenRouter 有成人使用限制。监护人同意本身不能覆盖 provider 的禁止性规定。当前应用不核验年龄，也不收集出生日期。未经适当授权，请勿输入儿童或其他人的个人信息。

权限、网站与政策更新

Android 应用使用网络权限连接 provider，并通过系统文档选择器处理你选定的文件，不请求通讯录、麦克风、相机或位置权限。键盘、操作系统及所选文档服务有各自的数据处理方式。

应用在「数据与隐私」中内置本政策的离线副本；上述公开地址始终提供最新版本。在浏览器中访问公开网站会单独连接 GitHub Pages；GitHub 可能按其隐私声明处理 IP 地址和技术请求信息：https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement 。网站源码未包含分析或广告脚本。

政策更新会在上述公开地址显示新的日期。如对 Green Bean Man 收到的信息有疑问或请求，请联系 greenbean.ai.app@gmail.com。
